# Weather Icons (vendored subset)

Directional arrows from [Weather Icons](https://erikflowers.github.io/weather-icons/) by Erik Flowers (SIL OFL 1.1), used for barometric pressure trend (rising / falling).

- `wi-direction-up.svg` — rising
- `wi-direction-down.svg` — falling

`pressure-flat.svg` is a small site-local glyph for steady pressure (not part of Weather Icons).
